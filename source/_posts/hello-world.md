## 为什么要写博客

其实想写博客很久了，一直没动手，理由无非是那几个：没时间、不知道写什么、觉得写了也没人看。

后来想明白了：**写博客首先是写给自己的**。

- 学过的东西不写下来，三个月后就忘得只剩「我好像见过这个」
- 能把一件事讲清楚，才算真正理解它
- 踩过的坑记一笔，下次能省半小时
- 攒下来的东西，本身就是一种复利

至于有没有人看，随缘就好。

## 为什么是 Hexo + GitHub Pages

选这套方案的原因很简单：不需要服务器、不需要数据库、不需要备案，文章就是一堆 Markdown 文件，放在 Git 仓库里，永远不会丢。

| 方案 | 服务器成本 | 维护成本 | 数据归属 |
| --- | --- | --- | --- |
| WordPress 自建 | 有 | 高（要管服务器、数据库、安全） | 自己 |
| 掘金 / 知乎等平台 | 无 | 无 | 平台 |
| **Hexo + GitHub Pages** | **无** | **低** | **自己** |

主题用的是 [Fluid](https://hexo.fluid-dev.com/)，清新、支持暗色模式和本地搜索，公式用 KaTeX 在构建时渲染好。
