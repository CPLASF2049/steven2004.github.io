为什么要写博客

其实想写博客很久了，一直没动手，理由无非是那几个：没时间、不知道写什么、觉得写了也没人看。

后来想明白了：写博客首先是写给自己的。

  • 学过的东西不写下来，三个月后就忘得只剩「我好像见过这个」
  • 能把一件事讲清楚，才算真正理解它
  • 踩过的坑记一笔，下次能省半小时
  • 攒下来的东西，本身就是一种复利

至于有没有人看，随缘就好。

为什么用 Hexo + GitHub Pages

选这套方案的原因很简单：

方案 服务器成本 维护成本 数据归属
WordPress 自建 有 高（要管服务器、数据库、安全） 自己
掘金 / 知乎等平台 无 无 平台
Hexo + GitHub Pages 无 低 自己

我不需要后台、不需要数据库，文章就是一堆 Markdown 文件，放在 Git 仓库里，永远不会丢。而且：

  • 完全免费，GitHub 自带 CDN
  • 想换主题就换主题，想加功能就装插件
  • 本地 hexo server 就能预览，写完 hexo deploy 一键发布

以后会写什么

大概会围绕这几个方向：

更新方向
编程笔记、工具效率、学习总结，偶尔写点生活随笔。

关于评论

本站的评论基于 GitHub Issue（Utterances）。你用 GitHub 账号登录就能留言，评论会以 Issue 的形式存在博客仓库里，不会丢，也没有广告。

就这些。希望这个博客能活得久一点 —— 至少比我的上一次尝试久。🙂
